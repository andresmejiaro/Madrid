# Evidencia

## Jerarquía

Para estado actual, acceso, horarios, obras y transporte: fuente oficial responsable, luego institución especializada, prensa reputada y finalmente reportes comunitarios.

Para historia: archivos, museos, universidades, patrimonio y bibliografía sólida.

Para folklore y memoria: historia local, proyectos de memoria oral, prensa, asociaciones y fuentes comunitarias pueden ser válidas si se conserva su estatus.

## Etiquetas epistemológicas

- `documented_fact`
- `plausible_or_disputed`
- `testimony`
- `cultural_memory`
- `oral_tradition`
- `legend`
- `folklore`
- `rumor_or_urban_myth`
- `inference`

No eliminar una leyenda por no ser hecho; no presentar una leyenda como hecho.
