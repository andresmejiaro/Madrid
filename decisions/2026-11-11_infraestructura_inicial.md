# Decisión: infraestructura inicial

**Fecha:** 2026-11-11

## Decisión

Crear un repositorio separado para Madrid y comenzar en fase de descubrimiento temático. No construir rutas todavía.

## Motivo

El proceso de París produjo rutas excelentes cuando la búsqueda temática acertó, pero perdió calidad cuando una tesis correcta se promovió demasiado pronto a geometría, cuando los kilómetros se convirtieron en umbral o cuando el objeto presencial no sostenía la promesa.

## Alcance de este commit

- extracción de lecciones de París;
- estados y proceso de promoción;
- rúbrica de temas;
- requisitos operativos conservados para fases futuras;
- banco inicial de 25 temas, expandido desde la conversación del día;
- plantillas y esquema de datos;
- ninguna ruta, waypoint o geometría.
