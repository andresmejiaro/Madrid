# Rúbrica para comparar temas

La rúbrica sirve para decidir dónde investigar, no para fabricar precisión. Las notas deben acompañarse de evidencia y pueden quedar como `unknown`.

| Dimensión | Pregunta |
|---|---|
| Identidad | ¿La experiencia puede describirse sin sonar como turismo genérico? |
| Pregunta central | ¿Existe una tensión o descubrimiento que pueda desarrollarse? |
| Densidad potencial | ¿Hay señales suficientes más allá de un único lugar? |
| Materialidad | ¿Habrá algo que ver, hacer, comparar, atravesar o percibir? |
| Arco potencial | ¿Puede existir apertura, desarrollo y payoff? |
| Distintividad | ¿Aporta una lectura que no posee ya otro tema? |
| Madrid específico | ¿Depende de esta ciudad o podría pegarse a cualquier capital? |
| Robustez | ¿Sobrevive si un interior, evento o punto condicional falla? |
| Potencial de franja | ¿Tiene razones reales para funcionar de mañana, tarde o noche? |
| Riesgo operativo | ¿Cuánto depende de permisos, horarios, obras, clima o señales invisibles? |

## Regla de interpretación

Una puntuación alta en historia no compensa materialidad nula. Una puntuación alta en materialidad no compensa un tema sin identidad. La promoción requiere una combinación defendible, no una media automática.
