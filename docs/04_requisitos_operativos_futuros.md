# Requisitos operativos para fases futuras

Este documento no autoriza todavía construir rutas. Conserva las cicatrices de París para que no se pierdan cuando llegue esa fase.

Cada ruta futura deberá tratar como productos distintos:

1. **Experiencia:** tema, arco, recompensas y final.
2. **Evidencia:** hechos, incertidumbre, fuentes y actualidad.
3. **Geometría:** orden físico, distancias y coste de transiciones.
4. **Navegación:** coordenadas exactas, lado de acceso, puertas y un punto ejecutable cada vez.
5. **Operación:** horarios, precio, baños, agua, comida con asiento, refugio, descanso y escapes.
6. **Narración:** guion audible que parte de lo visible y no compite con la navegación.
7. **Degradación:** qué se corta primero y qué núcleo debe sobrevivir.
8. **Auditoría de campo:** resultado real por parada y por montaje.

Un cierre operativo no puede declararse por inferencia. Acceso, apertura, ruta peatonal y estado actual requieren fuente responsable o comprobación de campo.
