# Temas

`theme_bank.md` es la lectura humana de las semillas. `catalog.json` es su estado estructurado.

Ninguna entrada representa todavía una ruta. No añadir direcciones, órdenes de visita ni geometría en esta fase. Cuando una semilla reciba investigación, usar `templates/theme_dossier.md` y actualizar su estado con una decisión trazable.
